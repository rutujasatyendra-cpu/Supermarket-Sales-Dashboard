# Supermarket Sales Data Analysis & Dashboard

## Project Overview
This individual project focuses on analyzing supermarket sales data and developing an interactive dashboard using Microsoft Power BI.

## Project Workflow
- **Data Analysis:** Explored sales performance across products, categories, dates, and cities.
- **Data Transformation:** Cleaned and transformed the dataset using Power Query.
- **Data Visualization:** Created charts, graphs, and slicers to explore sales insights.
- **Dashboard Development:** Built an interactive dashboard to analyze total sales, quantity sold, product performance, monthly trends, and city-wise sales.

## Tools Used
- Microsoft Power BI
- Power Query
- Microsoft Excel

- Power BI dashboard (`.pbix`)

Gained practical experience in data analysis, data transformation, visualization, and interactive dashboard development.
